# Task 1 — Student Grade Tracker

Console-based Java application using `ArrayList` to store students and grades.

## Features
- Input multiple students and subjects
- Validate scores from 0–100
- Calculate average, highest and lowest score per student
- Display pass/fail status
- Display class-level summary

## Run
```bash
javac src/StudentGradeTracker.java
java -cp src StudentGradeTracker
```
